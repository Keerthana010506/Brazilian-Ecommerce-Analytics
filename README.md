# Brazilian E-Commerce Analytics Dashboard

## Project Overview
Analyzed Brazilian e-commerce transaction data using MySQL and Tableau to identify payment trends, top-performing product categories, state-wise revenue distribution, and order growth patterns.

## Tools Used
- MySQL
- Tableau Public
- Excel

## Dashboard Insights
- São Paulo generated the highest payment value.
- Credit card was the dominant payment method.
- Cool Stuff and Beleza Saúde were top-performing categories.
- Orders showed steady growth from 2016 to 2018.
